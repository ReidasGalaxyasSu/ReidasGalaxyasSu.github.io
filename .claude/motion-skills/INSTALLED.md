# Motion skills instaladas

Fonte: https://github.com/iart-ai/motion-skills (índice) e os 19 pacotes `iart-ai/*-skills` que ele lista (licença MIT).
As 56 skills ficam em `.claude/skills/` e o Claude Code as carrega automaticamente nas sessões deste repositório.

Observação: `lower-thirds` existe em dois pacotes. A versão de `lower-thirds-skills` (transparente, para OBS/Premiere) ficou como `lower-thirds`;
a de `tiktok-video-skills` foi renomeada para `lower-thirds-short-form`.

Para atualizar: clone novamente os repositórios `iart-ai/<pacote>` e copie `skills/*` para `.claude/skills/`.
